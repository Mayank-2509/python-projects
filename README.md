# 🤖 Rule-Based ChatBot

A colorful, interactive rule-based chatbot built with **Streamlit** — upgraded from a simple CLI Python script into a full chat-style web app.

## ✨ Features

- 💬 Real-time chat interface with typing animation
- ⚡ One-click quick replies in the sidebar (hello, jokes, python, etc.)
- 📊 Live chat stats: messages sent, replies given, unanswered questions
- 🧠 90+ built-in rule-based responses across greetings, programming, general knowledge, math, fun facts, and more
- 🎉 Fun touches — balloons on "bye", emoji avatars, timestamps
- 🗑️ Clear chat / start a new conversation anytime
- 🎨 Custom dark gradient theme with neon accents

## 🚀 Getting Started

1. Clone the repo:

   ```bash
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```

2. Create a virtual Envvironment:

   ```bash
   python -m venv venv
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the app:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL Streamlit gives you (usually `http://localhost:8501`).

## 💡 Try asking

- "hello" / "hey" / "good morning"
- "who are you" / "what can you do"
- "tell me a joke" / "flip a coin" / "roll a dice"
- "what is python" / "what is machine learning"
- "largest planet" / "highest mountain"
- "bye" — to end the conversation

## 🛠️ Tech Stack

- [Streamlit](https://streamlit.io/) — chat UI framework (`st.chat_message`, `st.chat_input`)
- Pure Python rule-based matching (no external NLP libraries)
